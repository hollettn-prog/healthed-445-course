# HEALTHED 445 Module 2 Publishing Studio

Open `index.html` in a browser for preview, copy, and download. To publish on GitHub Pages, upload this folder's contents to your `healthed-445-course` repository under `publishing-studio/` and configure Pages to serve from the appropriate branch and directory, or use a repository-root landing page that links to `publishing-studio/`. GitHub Pages cannot serve a private repository without applicable plan and visibility settings.

**Do not upload private student information.** This sample uses course content from the provided export.

The original exported HTML is preserved as `pages/*-original.html`; the corresponding `pages/*.html` files are draft copies with navigation placeholders. Instructor video and Canvas URLs require manual verification.

Use the dashboard to copy the HTML into a matching Canvas page's HTML editor. Save and check the result before publishing.
