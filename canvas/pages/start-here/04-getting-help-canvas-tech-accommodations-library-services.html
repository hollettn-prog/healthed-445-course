Accessing Library Resources

Depending on your course, you may be asked to conduct academic research for activities, papers, or projects. The UW-Whitewater Andersen Library has friendly reference librarians ready to help you. The library home page is the gateway to all its resources, both print and electronic. Through the library, you can:

  1. Access electronic resources (including reserve items) 24/7.
  2. Freely borrow from other Universities of Wisconsin libraries through Universal Borrowing.
  3. Find high-quality information using research guides based on a subject or course.
  4. Chat live online with a reference librarian 24/7.

Off-Campus Library Access

Off-campus user access to licensed library databases is restricted to UW-Whitewater registered students, faculty, and staff only. Additionally, not all licensed databases provide off-campus access.

For more information on how to access online library resources off-campus, visit Library Services for Off-Campus Users. 

Here are some quick library links to get you started with any project quickly:

  1. User Guides - Learn how to find and use information at the UW-Whitewater libraries.
  2. Articles - Search for articles in journals, magazines, and newspapers.
  3. Ask a Librarian - Get reference assistance. Emailed questions are answered by UW-Whitewater librarians. Chat reference is run consortially, which means that answers may come from a librarian at another academic library, which may or may not be in Wisconsin.
